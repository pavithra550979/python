Python Activity-Based Learning
A collection of 10 real-world case studies implemented in Python using foundational programming constructs strictly aligned with the introductory Python syllabus.
Syllabus Scope & Constraints
All solutions are developed using only the following core concepts (without user-defined functions, dictionaries, sets, or external libraries):
Computational Thinking, Algorithms, Flowcharts, & Pseudocode
Variables, Data Types, & Operators
Conditional Statements (`if`, `elif`, `else`)
Loops (`for`, `while`, nested loops)
Strings & String Operations
Lists & Nested Lists (2D Matrices)
Tuples, Tuple Operations, & Tuple Unpacking

How to Run
Clone this repository to your local machine:
```bash
   git clone https://github.com/<your-username>/Python-Activity-Based-Learning.git
   cd Python-Activity-Based-Learning
   ```
Run any case study script using Python 3:
```bash
   python case_study_01.py
   ```
