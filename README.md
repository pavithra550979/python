# Python Activity-Based Learning (`Python-Activity-Based-Learning`)

This repository contains **10 completed Python case studies** developed for the **Python Activity-Based Learning** coursework. Every solution uses only the permitted syllabus topics:

* Computational thinking, algorithms, box-model flowcharts, and pseudocode
* Variables, data types, and operators
* Conditional statements (`if`, `elif`, `else`) and loops (`for`, `while`)
* Strings, lists, nested lists, tuples, tuple operations, and tuple unpacking
